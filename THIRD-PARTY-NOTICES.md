### Offline inventory and license payloads

The installed `agent-client-protocol` 0.12.1 headers omit license metadata, but
its `dist-info/licenses/LICENSE` contains the Apache-2.0 text, inspected during
M5 engineering. The inventory discovers these distribution license files too.
Final packaged license payloads and transitive obligations still require review
on the actual artifact before publication.
`DEPENDENCIES.json` generated by `packaging/dependencies.py` records the installed
runtime closure, including transitive dependencies, without installation paths
or source URLs. It is review evidence, not a legal/compliance certification.

## Build tools and embedded bootloader

Vite (MIT), TypeScript (Apache-2.0) and Playwright (Apache-2.0) are build/test
tools. Tailwind's emitted runtime CSS is covered by the frontend inventory.
The executable embeds PyInstaller's bootloader (GPL-2.0-or-later with the
Bootloader Exception, permitting packaged applications under their own license).
Its complete license/exception is shipped at
`_internal/licenses/bootloader/PyInstaller-COPYING.txt`.

The Node runtime's full version-specific license/third-party text is shipped
under `_internal/licenses/node-v<version>-LICENSE.txt`, separately from the
Python wheel wrapper's license. Builds refuse a missing matching license.
See [packaging/licenses/README.md](packaging/licenses/README.md) for provenance.

## LGPL notice for the packaged Windows/Linux builds

The GUI uses Qt 6 / PySide6 libraries available under LGPL-3.0. The package
keeps Widget/WebEngine and their QtQuick/Qml native bindings but excludes unused
QML application plugins, Charts/Graphs, PDF image rendering, VirtualKeyboard
and Quick3D profiling. Bundle preflight refuses those unreviewed add-ons.
LGPL is **not** a blanket classification of an entire installed Qt wheel.
The exact native inventory and Qt/Chromium third-party/source obligations are
recorded separately from application licensing and publication acceptance. The package uses PyInstaller's `onedir` layout: the Qt shared
libraries are separate DLL / ELF shared-library files inside the distribution
folder, so users can
replace them with modified or newer compatible versions. Qt source code is
available at https://download.qt.io/archive/qt/ (match the exact Qt version in
BUILD-INFO.json) and https://code.qt.io/. You may modify/replace compatible Qt
libraries and reverse engineer the application for debugging those modifications;
no Imece-specific prohibition restricts those LGPL rights. The LGPL-3.0
license text is available at https://www.gnu.org/licenses/lgpl-3.0.html.
Complete LGPL-3.0 and GPL-3.0 texts are shipped at `_internal/licenses/qt/`;
the wheel metadata alone does not contain them.

Runtime Python texts, frontend dependency texts (including required peers and
Tailwind CSS), font texts and their inventories are staged under
`_internal/licenses/`. Linux system-native copyright texts and referenced GNU
licenses are at `_internal/licenses/native/`. These inventories/texts are
engineering evidence, not proof of complete legal redistribution compliance.
