# Support

## Where to ask

- **Setup questions and general discussion:** [GitHub Discussions](https://github.com/FurkanKY/imece-ide/discussions).
- **Reproducible bugs or focused feature requests:** choose the matching
  [GitHub issue form](https://github.com/FurkanKY/imece-ide/issues/new/choose).
- **A potential security vulnerability:** use [private vulnerability
  reporting](https://github.com/FurkanKY/imece-ide/security/advisories/new),
  not a public issue, discussion, or pull request. See [SECURITY.md](SECURITY.md).
- **Conduct concerns:** use GitHub's report-content/block/report-abuse
  mechanisms as appropriate; do not submit ordinary conduct concerns as
  security advisories.

When requesting help, include the Imece version or commit, operating system,
runtime versions, whether you used the native desktop shell or browser mock,
steps to reproduce, expected and actual behavior, and sanitized diagnostics.
Name a provider route only if relevant; never post API keys, credentials,
private source code, personal data, or unredacted logs. There is no promised
response time.
